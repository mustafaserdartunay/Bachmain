# Designer Guide

## Open

`/belge-merkezi/tasarimci` or edit from Templates list.

## Modes

- **Görsel** — drag & drop canvas (default)
- **HTML** — advanced header/body/footer editors

## Add elements

Drag from left palette onto the page, or click an element type.

## Variables

Click a variable in the left panel to insert `{{path}}` into the selected text block.

## Save

Kaydet → tenant workspace sync (`flushWorkspaceNow`).

## Keyboard

- Delete / Backspace: remove selected block
- Undo / Redo via toolbar
