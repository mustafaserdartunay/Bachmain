# 06 — Label Designer

## Amaç
Sabit boyutlu etiketler (mm): 30×20, 50×30, 100×50, özel.

## Özellikler
- Sayfa = tek etiket; “sayfa başına N kopya” grid (2×3 vb.).
- Metin, logo, barkod, QR, çerçeve.
- Kesim payı / bleed opsiyonel (gelişmiş).

## Yazıcılar
- Termal (Zebra/TSC uyumlu PDF/ZPL ileride).
- MVP: tarayıcı print + PDF.

## Persist
`erlenbox-doc-labels` — soft-delete destekli.
